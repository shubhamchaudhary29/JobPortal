# Aggregation work rules

- Read `docs/aggregation-completion-plan.md` before aggregation work.
- Implement only the first unchecked milestone.
- Do not mark it complete until its acceptance tests pass.
- Update evidence and checkboxes before committing.
- Never skip ahead or claim the entire plan complete prematurely.
- If the first unchecked milestone cannot fit in one execution loop, split it into smaller independently verifiable child milestones, update and commit the plan, then continue with the first child. Do not return a no-change refusal merely because a milestone is oversized. Stop only for a genuine permission, environment or missing-requirement blocker.
